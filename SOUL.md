# SOUL.md — VIVAME Design

This file defines what VIVAME Design is and the standards every line of code, every
pixel of design, and every word of copy must honor. When in doubt, return here.

---

## 1. Who we are

**VIVAME Design** is an interior design, architecture, and 3D interior visualization
studio. Our digital presence must communicate, above all:

- Elegance
- Premium quality
- Creativity
- Architecture
- Attention to detail
- Trust
- Sophistication
- Professionalism

We are not a generic SaaS template, a generic corporate site, a cheap template, an
overly colorful startup landing page, or a cluttered dashboard.

## 2. The experience we build

The website should feel like a premium interior design studio — closer to an
architecture/interior-design editorial publication than a typical business website.

### Visitor journey

```text
Discover → Explore → Trust → Contact
```

A visitor must quickly understand:

1. Who VIVAME Design is
2. What VIVAME Design offers
3. The quality of its work
4. What kind of projects it handles
5. How to start a project

Never make visitors work unnecessarily hard to understand the business.

## 3. Design philosophy

Visual simplicity is intentional.

- Generous whitespace
- Strong typography
- Large imagery
- Editorial composition
- Refined spacing
- Subtle borders
- Restrained colors
- Elegant transitions
- Clear visual hierarchy

Avoid decoration. Every visual element must have a purpose.

### Portfolio-first thinking

The portfolio is one of the most important parts of our digital presence. When making
design decisions, ask: *does this help showcase the quality of VIVAME Design's work?*

Images are primary content, not decoration. Portfolio presentation should feel closer
to an architecture/design editorial publication than a generic project grid.

## 4. Quality bars (non-negotiable)

### Mobile is first-class
Never an afterthought. Touch interaction, navigation, typography, image cropping,
spacing, forms, performance, and readability are all designed for mobile, then refined
for larger screens.

### Accessibility is quality
Semantic structure, keyboard navigation, visible focus states, screen-reader support,
color contrast, form labels, alt text, reduced motion. A premium site is accessible.

### Performance matters
We are a visual business; unoptimized imagery is the fastest way to ruin the site.
Images are optimized, served in modern formats, responsive, and lazy-loaded. No
unnecessary JavaScript. Typography and font loading are managed deliberately.

### Security mindset
Assume external input is untrusted. Client-side validation is UX, not security.
Forms, uploads, and any future backend validate server-side. Rate-limit anything
public. Never expose secrets or sensitive data.

### Content honesty
Never fabricate clients, testimonials, awards, certifications, project statistics,
reviews, or achievements. If real content is unavailable, use clearly identifiable
placeholder content that is trivial to replace with the real thing later.

## 5. Brand voice

Professional, elegant, confident, warm, sophisticated, clear.

- No exaggerated marketing language
- No empty phrases that could describe any company
- Copy communicates real value

## 6. How we work (for humans and agents)

- **Project root:** `D:\SUAMI\project\vivame-design`
- The parent `D:\SUAMI\project` contains **unrelated projects**. Never create, modify,
  rename, move, or delete anything outside this project root.
- Preserve existing work. Understand code before changing it. Prefer incremental
  improvement over unnecessary rewrites.
- Fix root causes. Never hide problems. Never claim completion without verification.
- Reuse before duplicating. Keep the dependency footprint small and intentional.
- Simple, understandable solutions over clever complexity.
- Think from the visitor's perspective at every step.
